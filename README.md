[![Release](https://img.shields.io/github/v/release/kanatovs/taskflow-api?label=release)](https://github.com/kanatovs/taskflow-api/releases/tag/v1.0.0)

**[TaskFlow API v1.0.0](https://github.com/kanatovs/taskflow-api)** is a Go REST API for collaborative project and task management.

- JWT authentication with bcrypt password hashing and owner/admin/member authorization.
- Projects, tasks and comments; filtering, search, sorting and pagination.
- PostgreSQL with pgx, database migrations, parameterized SQL and transactions.
- Redis read-through detail caching with TTL, invalidation and PostgreSQL fallback.
- Docker Compose, OpenAPI documentation and GitHub Actions CI.
- Unit, integration, race, migration and smoke verification.

## Backend stack

- **Core:** Go, SQL, HTTP, REST and JSON.
- **Data:** PostgreSQL with pgx; Redis caching.
- **Access control:** JWT, bcrypt and role-based authorization.
- **Tools:** Docker Compose, OpenAPI, Git and GitHub Actions.
